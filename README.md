# Scorilo

Stadionanzeige und Spieltagsshow für Fußballvereine – für macOS und Windows.

Download, Preise, Versionshinweise und Hilfe: **[scorilo.de](https://scorilo.de)**

Dieses Repository enthält nur die veröffentlichten Scorilo-Versionen: die
Installationsdateien für macOS und Windows und die Update-Daten, die
installierte Scorilo-Kopien lesen. Versionen kommen ausschließlich über die
Release-Pipeline der Anwendung hierher.

---

Scorilo is the stadium display and matchday show for football clubs. This
repository only hosts the published releases and their update metadata.
Everything else is on [scorilo.de](https://scorilo.de).
